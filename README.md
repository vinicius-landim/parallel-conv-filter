# parallel-conv-filter

Como executar (Windows):

```bash
cd src\
```

```bash
gcc -o conv_filter conv_filter.c -lm

```

```bash
.\conv_filter.exe ..\data\nome_imagem_RGB
```

(obs: -lm precisa para compilar as funções do stb_image)
